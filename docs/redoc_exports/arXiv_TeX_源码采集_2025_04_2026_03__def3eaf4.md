## 存储结构

TeX 文件与已有 metadata 并排存放：

```plaintext
data/arxiv/papers/&lt;year&gt;/&lt;month&gt;/&lt;arxiv_id&gt;/
  metadata.json       # 已有文件（此前爬取的 305k 条 metadata）
  tex/
    .done             # sentinel：仅在成功提取后写入
    paper.tex         # 单文件投稿
    *.tex             # 多文件投稿（路径已打平，保留原始文件名）
```

## 脚本说明

### data/arxiv/download_tex.py — 并行下载器（新增）

读取已有的 metadata.json，跳过已存在 tex/.done 的论文，从 https://arxiv.org/e-print/&lt;arxiv_id&gt; 下载 e-print tarball 并提取 .tex 文件。

```bash
# 单机运行（处理全部论文）
python data/arxiv/download_tex.py --from-month 2025-04 --until-month 2026-03 --workers 16

# 多机分片运行（每台机器执行对应命令）
python data/arxiv/download_tex.py --shard 0/4 --workers 16 --request-delay 1
python data/arxiv/download_tex.py --shard 1/4 --workers 16 --request-delay 1
python data/arxiv/download_tex.py --shard 2/4 --workers 16 --request-delay 1
python data/arxiv/download_tex.py --shard 3/4 --workers 16 --request-delay 1
```

关键参数：--shard K/N 按排序后的论文目录索引取第 K 片（各机器分片不重叠，无跨机冲突）；--workers 控制线程池大小；--request-delay 为每个线程完成下载后的等待时间。

### data/arxiv/crawl_arxiv.py — metadata 爬虫（已更新）

新增 --download-tex 参数，可在 OAI-PMH metadata 爬取过程中同步下载 TeX 源码。批量补采时推荐直接使用 download_tex.py（更快，跳过 OAI-PMH 流程）。

## 性能

4 台机器 × 16 线程 × ~2.5 次下载/秒 = 292k 篇论文约 **8 小时** 完成（对比顺序执行约需 13 天）。瓶颈为网络带宽（arXiv e-print endpoint）。
