Core idea: Introduce **Learned Spatial Attentive Pooling (LSAP)** that dynamically computes spatial attention weights via a lightweight 1×1 convolution followed by spatial softmax, allowing the model to focus on task-critical regions while gracefully degrading to uniform weighting for 1×1 inputs. The attention mechanism learns to emphasize discriminative spatial patterns (e.g., object centers in ResNet's 8×8 maps) without requiring architectural changes.

Non-trivial crux: Designing a spatial attention module that (1) operates on variable H×W inputs using globally consistent operations (1×1 conv + spatial softmax), (2) maintains parameter efficiency (only ~C parameters for input [B,C,H,W]), and (3) avoids overfitting by sharing attention weights across channels via a bottleneck projection, ensuring generalization across architectures (ResNet's 8×8 vs VGG's 1×1).
