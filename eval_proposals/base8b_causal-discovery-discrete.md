Core idea: Integrate Bayesian network structure learning with constraint-based skeleton discovery by using the data's conditional probability distributions to refine edge orientations beyond standard conditional independence tests. This leverages the fact that discrete data from a Bayesian network inherently encodes directional relationships in its CPTs, allowing us to infer edge directions through probabilistic consistency checks rather than relying solely on independence tests.  

Non-trivial crux: Accurately estimating the CPTs from observational data to detect probabilistic dependencies that indicate edge directionality, while avoiding overfitting to noise in the discrete variables. This requires a balance between local structure learning (for CPT estimation) and global constraint satisfaction (for CPDAG formation).
