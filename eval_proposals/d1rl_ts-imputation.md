**Mocking:** World-Class AI Researcher

Let me not start from any model. Let me start from what MUST be true about missing value imputation, and ask: where does the default design betray this?

The default design treats imputation as a simple 'fill the hole' problem. But in time series, a hole is not a hole — it is a *context gap*. The model sees a contiguous segment, and somewhere in the middle a block of zeros. The zeros are not 'missing'; they are *absent context*. So the honest question is: how much of the imputation task is about *recovering missing input* versus *recovering the model's own internal state*?

Here's the deductive leap, and it's the only place I'll be non-consensus. Most people, given a masked region, learn to interpolate the gap — a one-dimensional recovery. But a gap is not a gap: it is a *hole in the causal chain*. The causal information that would normally flow through the missing part is now blocked. So the true task is not 'predict y_t' but 'predict the hidden state that would have been there'. The hidden state at the gap is what the model should be imputing, not the scalar values. This is a reframe, not a refinement: imputation becomes a latent-state restoration problem, and interpolation becomes an *intermediate step* in a larger recovery.

Now the obvious move is to keep the same architecture and just change the output head to a latent state. But that's the trap I want to avoid: it's a cheap rebranding, not a real mechanism. If I only change the head, the model still treats the gap as a place to interpolate. The causal chain is not fixed. So the real design choice is not 'output a latent state' — it's 'output a latent state AND force the model to *learn* what a gap looks like'. I need to inject a mechanism that makes the model *aware of its own missingness*, so it can actively fill the gap from its internal representation rather than from the raw inputs.

Two things must change simultaneously to make this work. First, the *architecture*: I should add a skip-connection from the hidden state at the gap position back into the output head — a recurrent-style loop. This lets the model feed its own imputed state through the gap, turning a single-step interpolation into a multi-step internal-state propagation. Second, the *objective*: I should add a regularization term that penalizes the hidden state at the masked positions to be *close to zero*. Zero is the natural prior for a recurrent loop — it means 'no input here, pure internal memory.' If I don't penalize it, the hidden state can drift and the loop fails to close. The two are linked: the regularization makes the loop *necessary*, not just nice.

Why is this the non-trivial crux? Because most imputation papers treat masking as a boundary condition. I'm claiming masking is the *internal boundary* of a recurrent loop — and that claim only holds if the regularization is attached to the hidden state, not to the output. If I omit the regularization, the loop never stabilizes, and I've only renamed the problem. And the reward function is not just a loss — it's a *state prior*: zero at masked positions is the prior, and the model is rewarded for converging to it. That's what turns this from a clever idea into a mechanism.

How do I keep myself honest? I won't declare victory on a single metric. I'll compare two versions of the same architecture on the same masked datasets: one with the regularization loop, one without. Decision rule: if the regularization loop does not clearly improve MSE/MAE on masked regions across all three datasets, I keep the simpler form. If it helps, I attribute any gap between the patched model and the reference baselines to the regularization, not to architecture. And I'd probe the regularization strength: if I over-penalize, the hidden state can collapse to zero and the model forgets the inputs — that's the failure mode I'm guarding against. The model only counts if the loop is *necessary* and the regularization is *minimal*.

**Core idea:** Reframe imputation as latent-state restoration and add a recurrent-style skip-connection plus a hidden-state regularization term (zero at masked positions) — so the model learns to fill gaps from its own internal state rather than from interpolation.
**Non-trivial crux:** The regularization must be attached to the hidden state (zero prior at masked positions), not the output; otherwise the loop never stabilizes and the rebranding is empty — the gap is only an internal boundary because the model is forced to remember its own missingness.
