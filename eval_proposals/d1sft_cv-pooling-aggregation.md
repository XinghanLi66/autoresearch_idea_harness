**Mocking:** AI Researcher

Let me start from what MUST be true, not from what I'd like to see. The input is [B, C, H, W] with C varying across architectures and H/W being whatever the network produces — for ResNet-56 it's 8×8, for VGG-16 it's 1×1, for MobileNetV2 it's 1×1. That's the invariant: spatial size is not fixed. So any strategy I design must not assume a fixed spatial grid. It must work on any grid. That's the first constraint.

Now, what breaks. Standard GAP and GMP are both 'point' statistics: they take one number per channel. That throws away a lot of information — the full spatial distribution of activations. So the question isn't 'which point statistic is best' — it's 'why do we have to take a single number at all?' If the goal is to capture the full distribution, the natural answer is: don't. Instead, represent each channel by its full histogram. That's the leap I want to make.

Why a histogram? Because it is a discrete summary of the spatial distribution — it's a *multiset* of activations, not a scalar. And crucially, a histogram is *scale-invariant*: if I multiply the input by a constant, the histogram's bins just rescale. That property is exactly what I need to make the pooling adaptive to the input scale. It's also what makes it 'learnable' — the bins themselves are parameters, so the model can adapt the binning to the feature map it receives. A point statistic like mean is fixed to a particular scale, and a learned mean (GeM) still carries an explicit scale parameter that is optimized per-image, not per-feature-map.

So the design: a learnable binning that partitions each channel's activations into a fixed number of bins (say N), then collect the bin counts (which sum to H×W) and use them as the final feature vector. This is a natural extension of the idea in GeM to a multi-bin form — the power mean is a special case of a binning at two bins. The count vector is [B, C, N] and I then project to [B, C] via a linear layer. I can also add a learnable attention layer on top of the counts to weight each bin — that's a second layer of parameters, and it lets the model adapt the importance of different spatial scales per channel. Two layers of learnable parameters: binning and bin-attention. The total number of parameters is fixed and small (N*C + C*C), so the binning shouldn't hurt training stability.

Why this cuts against the consensus: the field's default is to optimize a scalar per channel — GeM, adaptive pooling, etc. My claim is that the scalar is the wrong object to learn, because it is forced onto a fixed scale and thus can't adapt to the input. A histogram, on the other hand, is a self-adapting statistic that is invariant to input scale and encodes the full distribution. It's not a scalar, it's a multiset — and the multiset property is exactly what I'd expect to carry more information.

Now, how do I keep myself honest. I should not just assume this works; I need to validate the design on the exact constraints. Decision rule: compare the proposed histogram pooling (with N=8 and an optional attention layer) against the current best in the file — for the evaluation setting, that's GeM and Average+Max — on ResNet-56 and VGG-16 on CIFAR-100. If the histogram version doesn't clearly beat the alternatives on test accuracy, I fall back to the simpler, well-understood option and add the attention only if it helps. I'll also check that the binning stays stable across different feature map sizes — if the bins drift too much, I'll add a learnable spatial bias to the binning to keep it anchored.

Non-trivial crux: the histogram is only useful because it is *scale-invariant* — the same binning works on any spatial size, so it can adapt to the input without explicit per-feature-map normalization; without that invariance, the binning would collapse to a fixed-scale mean and the whole idea would be just a reparameterization of GeM.

**Core idea:** Instead of averaging or max-pooling each channel, learn a fixed number of bins per channel, count the activations in each bin, and project the bin counts — a scale-invariant, distribution-preserving representation — with an optional attention layer to weight the bins.
