**Core idea:** Treat the task as recovering the Markov Equivalence Class (MEC) represented by a CPDAG — the only quantity identifiable from observational data under faithfulness — and build a score-based algorithm that (1) uses a Bayesian score derived from the Bayesian-network factorization, (2) applies v-structure rules to orient edges from the skeleton, (3) searches via stochastic local search with restarts to escape local optima, and (4) evaluates only with a CPDAG-aware metric (not against the true DAG).

**Non-trivial crux:** The algorithm must be *aware of what the data identifies* — observational data cannot distinguish the true DAG from its MEC, so any method claiming to return a DAG is fundamentally flawed and any evaluation against the true DAG is measuring an impossible target; the CPDAG F1 must be the sole score, and the skeleton estimation plus v-structure rules must be explicitly CPDAG-aware to avoid returning a false partial order.
