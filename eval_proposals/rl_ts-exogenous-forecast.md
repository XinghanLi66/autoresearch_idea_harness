Let me start from what the reference models actually do — because that's where a real improvement should come from, not from adding random bells and whistles. I'll take DLinear as the base point since it's a simple yet competitive linear model, and compare it explicitly against PatchTST and iTransformer.

DLinear splits the input into trend and seasonality components, processes them separately with different lags, then combines them. Its strength is that it captures the temporal structure without complex machinery — which means its weakness is exactly that it doesn't capture interactions between the exogenous variables themselves. A naive MLP would have the opposite problem: it can learn rich interactions but has no built-in sense of temporal structure.

So let me look at the two reference architectures that *do* handle both — PatchTST and iTransformer — and ask what mechanism they share, rather than copying either wholesale. Both inject exogenous information *through the attention mechanism*. PatchTST does it via a patch-wise attention scheme, and iTransformer does it via a learned positional encoding that implicitly carries external signal. That shared mechanism is the one I want to isolate and adapt, not the whole architecture.

Here's the reasoning leap: if attention is the way to inject exogenous information *and* maintain temporal structure, then the question becomes — what is the minimal form of that? A full Transformer with self-attention is heavy machinery. A single cross-attention layer is much lighter, and it still gives me the key property: it allows each output position to condition on *all* input positions (temporal structure) while also conditioning on *all* exogenous features at once (rich interaction).

Why this cuts against the default move: the instinct is to add complexity — more layers, a fancier backbone, or a hybrid. But the real constraint here is that I'm already working inside a limited framework that will train and evaluate this model across multiple datasets. A single cross-attention layer is precisely the sweet spot — it adds enough expressive power to beat plain DLinear, but stays light enough to fit within the training budget and be robust across different datasets.

Now the caveat I must keep honest about: cross-attention alone is blind to the absolute position of tokens in time, so it may struggle with long-range dependencies unless I also supply some form of positional encoding. That's not a reason to abandon the idea — it's an integral part of it. So my plan is: add a single cross-attention layer, plus a simple learned positional encoding, and verify whether the gain comes from the attention or the positional encoding.

**Core idea:** Replace the linear trend-seasonality split of DLinear with a single cross-attention layer over all input positions and all exogenous features, paired with a learned positional encoding — capturing both temporal structure and feature interactions with minimal added complexity.

**Non-trivial crux:** Cross-attention alone is position-blind, so the learned positional encoding is not optional decoration; it is what enables the model to capture long-range temporal dependencies, making the combination work rather than the attention layer alone.
